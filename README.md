# Inspection showcase

Static gallery of saved inspection results. Open index.html to browse locally.

Upload the contents of this folder to your GitHub Pages publishing folder, keeping index.html at its root. Preserve the images folder and relative file paths.

All cases opens by default. Filters, featured photos, zoom, and available reading marks remain interactive. This website displays saved results; it does not run inference or connect to Orbit. To publish newer readings, regenerate the static gallery from updated results.
